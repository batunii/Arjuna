## Rebuilding

```
./build.sh          # or build.bat on Windows
```

Equivalently:

```
pdflatex thesis
bibtex   thesis
pdflatex thesis
pdflatex thesis
pdflatex thesis
```

Or, if you have it, `latexmk -pdf thesis`, which iterates to convergence on its own.

All five passes are required. Pass 1 writes `thesis.aux` and the per-chapter
`content/*.aux` files. BibTeX reads those to build the bibliography. Passes 3 and 4
pull in the bibliography, the table of contents, the lists of tables and figures, and
move the page cross-references. Pass 4 still emits "Label(s) may have changed", because
the longtables and the lists of tables and figures shift page breaks as they are filled
in, so pass 5 is what settles them. `build.sh` checks for that warning in its summary,
and a non-zero count there means the cross-references are not yet settled.

**Do not delete `content/*.aux` between passes 1 and 2.** Every `\citation{}` record
lives in the per-chapter aux files, not in `thesis.aux`, so removing them makes BibTeX
emit an empty bibliography with no error.

One non-obvious point about page style. `tcdthesis.sty` defaults `\@textpagestyle` to
`fancy` and applies it at the first `\chapter`, but it never loads `fancyhdr` and never
configures that style. The only thing in the style file that changes `\@textpagestyle` is
`\thesisdraft`, which the shipped template leaves on and a submission must turn off, so the
`fancy` path is one no one ever intended to run. `thesis.tex` therefore selects `plain`
explicitly, which matches the front matter: page numbers at the bottom centre, no header
and no header rule. Deleting that `\renewcommand` makes the first `\chapter` fail on
`\undefinedpagestyle` unless `fancyhdr` is loaded, and loading `fancyhdr` brings its stock
defaults, a rule across every body page and the page number moved into the header.

## Status of the work reported

Data collection is complete. Twenty people were tested, all completing the full two-block
protocol, matching the planned recruitment headcount; the pre-registered target was set in analysed
participants and is not met on either block, and no supplementary participants were added. Block A has nineteen usable paired participants, Block B seventeen, and twenty
end-of-session questionnaires were completed.

Every statistic traces to `../authored/analysis-2026-08-12-pooled-final.md`, which supersedes
`../authored/analysis-2026-08-08-pooled-n17.md` and everything before it. It is
regenerated by `Tools/analysis/blocka_pooled.py`, `blockb_pooled.py`, `esq_extract.py`
(questionnaire totals) and `loo_sensitivity.py` (leave-one-out table), and never hand-edited.
It carries a "superseded figures — do not use" table; any figure from that column appearing in
the manuscript is a bug.

All figures are drawn and placed, in `content/figures/` (the generated ones by
`content/figures/generate_all.py`). No `\figplaceholder` boxes remain: `grep -rn figplaceholder
content/` returns nothing, and all 27 image files the chapters reference are present on disk.
The macro is still defined in `thesis.tex` so that a future figure can be reserved with it.

## Structure

Six chapters: introduction, background, design space, system, user study, conclusion. The
benchmark-plan chapter was removed because none of its benchmarks were run; its one real
result, the offline detection bake, now sits in Chapter 4 alongside the oracle pipeline that
produced it. The separate discussion chapter was dissolved, with its results discussion
moved beside the numbers in Chapter 5 and its limitations, transfer and future work into
Chapter 6. Protocol artefacts that make the study reproducible but do not need to be read in
sequence — session timeline, analysis plan, decision table, operational protocol, threats to
validity — live in Appendix A.
