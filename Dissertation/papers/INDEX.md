Nothing here came from a paywall bypass: the routes used were arXiv, Europe PMC, publisher open access, author and repository copies recorded by OpenAlex and Semantic Scholar, and PDFs already fetched into this project in earlier sessions.

**Every file in this folder was verified** — either the DOI/arXiv id printed inside the PDF matches the citation, or the cited title appears verbatim on page 1. Fuzzy title matching produced several wrong matches during assembly; those were rejected rather than filed, because a wrong PDF under a citation is worse than a missing one.

These three fix the eccentricity bands the ring result depends on. All were traced to an exact
reference on 2026-07-30; none has an open-access copy anywhere, so all three need a Trinity login
(the first two) or a library request (the third — a 1993 print journal that appears never to have
been digitised).

  to in-vehicle task difficulty. *Transportation Research Part F* 8(2), 167–190. — the ~8° road-centre
  region, which sets the inner band boundary.
  <https://doi.org/10.1016/j.trf.2005.04.014>

  measure in driving. *Transportation Research Part F* 8(3), 255–275. — the Peripheral Detection Task
  places its probes at 11–23°, which is the load-sensitive middle of the band.
  <https://doi.org/10.1016/j.trf.2005.04.009>

  Optometric Association* 64(1), 71–79. PMID 8454831. — the ≈30° outer boundary and the ±35°
  distractor placement. Not in Crossref, no DOI, no online copy found.
  <https://pubmed.ncbi.nlm.nih.gov/8454831/>
